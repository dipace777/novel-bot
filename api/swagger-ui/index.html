From account to API key

  1. Register & log in. Execute the public authentication routes below.
  2. Authorize your session. Paste access_token into LoginSession to manage keys.
  3. Test your app key. Paste api_key into ApplicationBearer or ApplicationKeyHeader to call /v1/whoami.

Paste the token value without the Bearer prefix. Authorization stays in this page's memory and clears on reload.
