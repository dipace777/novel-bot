# Playwright examples

The test in `playwright/example.spec.ts` creates a Novel Bot browser session,
connects through the authenticated CDP proxy, visits `https://example.com`, and
checks the page. It waits five seconds after successful checks, then deletes
the session. Cleanup also runs when connection, navigation, or assertions fail.

Run the commands below from the repository root.

## Start the application

Use Node.js 24 and pnpm for the examples. Configure the root `.env` as described
in the [project setup](../README.md#run-locally), then start the dependencies
and API:

```sh
make db
make migrate
make run-api
```

In another terminal, start the Chromium worker:

```sh
make run-worker
```

Chromium or Google Chrome must be available on the worker machine. The example
connects to that browser remotely; it does not launch its own local browser.

## Configure the example

Install dependencies and create the example environment file if it is absent:

```sh
pnpm --dir examples install --frozen-lockfile
test -f examples/.env || cp examples/.env.example examples/.env
```

To generate an application API key, run `make run-ui`, open
`http://localhost:3000`, sign in, and select **Create API key**. Copy the secret
from the one-time dialog into `examples/.env`:

```dotenv
NOVEL_BOT_API_KEY=your-generated-application-api-key
NOVEL_BOT_API_URL=http://127.0.0.1:8080
```

Use the application API key, not the account login token. Playwright automatically
loads `examples/.env`; exported environment variables take precedence.
`NOVEL_BOT_API_URL` is optional and defaults to `http://127.0.0.1:8080`.

## Run the test

With the API and worker running:

```sh
pnpm --dir examples exec playwright test \
  --project=chromium --workers=1 --retries=0
```

This selects Chromium, runs one Playwright test worker, and disables retries.
Each test creates and deletes its own Novel Bot session.

To inspect a visible browser window, set `BROWSER_HEADLESS=false` in the root
`.env` and restart `make run-worker`. The five-second inspection pause is in
`example.spec.ts`, immediately before session cleanup.

Open the saved HTML report with:

```sh
pnpm --dir examples exec playwright show-report
```

After a failed run, Playwright may serve the report automatically on port 9323.
Press Ctrl+C to stop that report server before rerunning the command.

## Troubleshooting

- **Missing API key:** check `NOVEL_BOT_API_KEY` in `examples/.env`.
- **HTTP 401:** use a valid, unrevoked application key generated by the UI.
- **Connection refused:** check the API is running and `NOVEL_BOT_API_URL` matches its address.
- **HTTP 503 during session creation:** check the worker is running and has available capacity; inspect its logs for browser startup failures.
- **HTTP 429:** tenant concurrency or request limits have been reached; wait for capacity or the rate-limit window to reset.
